# Практическое занятие 7

Node.js API с базовой аутентификацией (bcrypt) и CRUD для товаров.

## Запуск

```bash
npm install
npm start
```

Сервер: `http://localhost:3000`

## Маршруты

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/products`
- `GET /api/products`
- `GET /api/products/:id`
- `PUT /api/products/:id`
- `DELETE /api/products/:id`
