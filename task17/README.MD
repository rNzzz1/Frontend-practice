# Практическое занятие 17

Доработка приложения из практики 16: добавлены push-напоминания с возможностью
отложить уведомление на 5 минут.

## Что реализовано

1. Форма для обычной заметки и отдельная форма для заметки с напоминанием (`datetime-local`).
2. Структура заметок в `localStorage`:
   - `id` (уникальный идентификатор)
   - `text`
   - `reminder` (timestamp или `null`)
3. На сервере реализовано планирование напоминаний:
   - хранение активных таймеров в `Map`
   - запуск через `setTimeout`
4. В Service Worker реализовано:
   - получение `push`
   - action-кнопка `Отложить на 5 минут`
   - обработка `notificationclick` и POST на `/snooze`
5. Подписка на push через `PushManager` + `web-push` на сервере.
6. Для проверки добавлена кнопка `Тест Push`.

## Важные доработки для стабильности

- VAPID-ключи сохраняются в `vapid-keys.json`, чтобы push не ломался после перезапуска сервера.
- При загрузке страницы существующая браузерная подписка автоматически синхронизируется с сервером.
- Напоминание отправляется на сервер через REST (`POST /api/reminders`), поэтому не зависит от состояния Socket.IO.

## Как проверить push на macOS

1. Открой приложение по `http://localhost:3017` (или `http://localhost:3037`).
2. Нажми `Включить Push` и разреши уведомления в браузере.
3. Нажми `Тест Push`.
4. Если в интерфейсе написано `доставлено 0`, значит подписка неактивна, нажми `Включить Push` повторно.
5. Если браузер разрешил, но системного окна нет: проверь `System Settings -> Notifications -> Chrome/Edge`.

## Проверка сценария напоминания

1. Создай заметку с напоминанием на 1-2 минуты вперед.
2. Дождись push-уведомления.
3. В уведомлении нажми `Отложить на 5 минут`.
4. Через 5 минут придет повторное уведомление.
