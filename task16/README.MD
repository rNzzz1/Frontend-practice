# Практическое занятие 16

Версия без `Service Worker`: уведомления работают через `Notification API` и `Socket.IO`.

## Что реализовано

- HTTPS сервер для локального запуска.
- Realtime-канал через `Socket.IO`.
- Уведомления без SW:
  - кнопка `Включить уведомления` запрашивает разрешение браузера;
  - кнопка `Отключить уведомления` полностью выключает показ уведомлений;
  - уведомления показываются при событиях от других клиентов.
- Архитектура `App Shell` сохранена:
  - shell интерфейса
  - динамические страницы `/content/home.html` и `/content/about.html`

## Важно про установленное приложение

В установленной версии (PWA окно) уведомления тоже работают, если приложение запущено и разрешение на уведомления выдано.

## Как проверить

1. Открой приложение в двух окнах/вкладках.
2. В обеих вкладках нажми `Включить уведомления` и разреши доступ.
3. В первой вкладке добавь заметку.
4. Во второй вкладке увидишь событие в блоке realtime и системное уведомление.
5. Нажми `Отключить уведомления` во второй вкладке.
6. Повтори добавление заметки: системного уведомления во второй вкладке уже не будет.
