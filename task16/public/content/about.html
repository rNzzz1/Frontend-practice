О нас

Эта версия заметок доработана в рамках практики 16: подключены Socket.IO и уведомления браузера без Service Worker.

  • Shell интерфейса кешируется стратегией Cache First.
  • Динамические страницы /content/* грузятся по Network First.
  • При добавлении заметки сервер рассылает событие другим клиентам по Socket.IO.
  • Клиенты с включенными уведомлениями получают системное уведомление через Notification API.
