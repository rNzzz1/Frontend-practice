# Практическое занятие 14

Продолжение 13-й практики: приложение заметок оформлено как `PWA` через `Web App Manifest`.

## Что реализовано

- просмотр списка заметок
- добавление новых заметок
- удаление заметок
- хранение данных в `localStorage`
- регистрация `Service Worker`
- кэширование статических ресурсов
- работа страницы без интернета после первого открытия
- подключен `manifest.json`
- добавлены иконки приложения
- настроены `name`, `short_name`, `start_url`, `display`, `background_color`, `theme_color`
- добавлена кнопка установки приложения
- добавлены mobile/PWA meta-теги

## Структура

- `server.js` - статический сервер для запуска приложения
- `public/index.html` - интерфейс приложения
- `public/app.js` - логика заметок, регистрация `Service Worker` и установка PWA
- `public/sw.js` - кэширование файлов и офлайн-режим
- `public/offline.html` - резервная офлайн-страница
- `public/manifest.json` - описание PWA
- `public/icons/*` - иконки приложения

## Как проверить

### Офлайн-режим

1. Открыть приложение в браузере.
2. Убедиться, что `Service Worker` зарегистрировался.
3. Добавить несколько заметок.
4. Отключить сеть в DevTools.
5. Обновить страницу.
6. Приложение должно открыться из кэша, а заметки остаться доступными из `localStorage`.

### Web App Manifest

1. Открыть `DevTools -> Application -> Manifest`.
2. Проверить:
   - название приложения
   - иконки
   - `start_url`
   - `display: standalone`
   - `theme_color`
3. Нажать кнопку установки приложения, если браузер показывает install prompt.

## Что показать преподавателю

1. Регистрацию `Service Worker` в DevTools.
2. Наличие файлов в `Cache Storage`.
3. Наличие заметок в `localStorage`.
4. Раздел `Application -> Manifest`.
5. Работу приложения после отключения интернета.
6. Установку приложения через кнопку `Установить приложение`.
